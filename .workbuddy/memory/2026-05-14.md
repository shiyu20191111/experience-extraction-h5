## 修复数据写入问题：H5提交数据自动同步到腾讯文档

### 问题
H5提交后数据只保存到localStorage，从未自动写入腾讯文档汇总表。

### 解决方案
采用"H5提交 → GitHub仓库 → WorkBuddy每日automation → 腾讯文档"三层架构：

1. **H5改造**（`submitValidation`）：
   - 提交时异步调用 `submitToGitHub(formData)`
   - 将数据以JSON文件写入GitHub仓库 `data/submissions/{timestamp}_{employeeId}.json`
   - 使用 GitHub Contents API（PUT方法），base64编码数据
   - token做了简单混淆（字符串拼接），避免直接裸露

2. **GitHub仓库目录结构**：
   - `data/submissions/` — 待同步的新记录
   - `data/synced/` — 已写入腾讯文档的记录（作为存档）

3. **WorkBuddy automation**（ID: `automation-1778720077942`）：
   - 每天 08:30 自动运行
   - 读取 `data/submissions/` 目录的JSON文件
   - 解析数据，写入腾讯文档汇总表（file_id=`LucoMsfAfyCU`，sheet_id=`BB08J2`）
   - 写入成功后将文件移到 `data/synced/`（先创建再删除原文件）

### 腾讯文档汇总表信息
- file_id: `LucoMsfAfyCU`
- sheet_id: `BB08J2`
- 20列：序号(0)、姓名(1)、工号(2)、部门(3)、选题(4)、选题来源(5)、高价值分(6)、紧迫度分(7)、常发生分(8)、三维度总分(9)、萃取价值(10)、是否有成功案例(11)、弯路教训(12)、期望效果(13)、目标学员(14)、选题是否一目了然(15)、是否修改选题(16)、修改后选题(17)、提交时间(18)、状态(19)
- 数据从 row=1（第2行）开始写入，row=0 是表头
